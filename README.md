git 

cd 프로젝트명    > 프로젝트 위치로 이동
git init              > 해당 프로젝트를 git 프로젝트로 초기화
git branch -m main   > git은 기본적으로 master/slave 의 명칭을 쓰는데 미국에서 주종관계의 표시를 싫어해서 사용안하기로함
                                 그래서 master로 되어있는걸 main으로 바꿔줘야함 ( github, gitlab 은 main을 씀 )
git add .             > 깃에 커밋할 파일 전체 등록 . 말고 다른 파일명을 지정해도 됨
git commit -m "커밋 내용 코멘트작성"
